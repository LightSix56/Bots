# KemonoDroid

Android-порт [Kemono-Downloader](https://github.com/Yuvi9587/Kemono-Downloader) (Yuvi9587):
качает посты и файлы с Kemono / Coomer прямо на телефон.

## Что умеет (v0.1)

- ссылка на автора или на отдельный пост (`kemono.su/cr/party`, `coomer.su/st/party`);
- режимы: всё / картинки / видео / архивы / аудио / только ссылки (`links.txt` из описаний постов);
- фильтры: «только если в названии…», слова-исключения, `[200]` — пропуск файлов меньше 200 МБ,
  область применения (посты / файлы / оба), вырезание слов из имён файлов;
- отдельная папка на пост, диапазон страниц, несколько потоков;
- пауза / продолжить / стоп, прогресс в уведомлении (фоновый foreground-сервис);
- cookie сессии и ручная смена домена, если зеркало заблокировано;
- ссылку можно отправить в приложение через «Поделиться».

Файлы сохраняются в `Загрузки/KemonoDroid/<автор>/<пост>/`. Разрешение на память не нужно.
Уже скачанные файлы пропускаются при повторном запуске.

## Сборка

Из Android Studio или `./gradlew :app:assembleDebug` (нужен Android SDK).
В репозитории настроен GitHub Actions (`.github/workflows/android.yml`): на каждый пуш собирает APK
и выкладывает его в релиз `kemonodroid-latest`, откуда его можно скачать с телефона.

Модуль `core` — чистый Kotlin/JVM без Android, его тесты идут без SDK: `./gradlew :core:test`.

## Что пока не перенесено из оригинала

ревизии постов, Google Drive / Mega, режим манги с нумерацией.
